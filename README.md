# CountMatch — App de Estoque para a Rafimex

> **Contar. Comparar. Corrigir.**
> Protótipo de aplicativo mobile para controle e auditoria de estoque da **Rafimex — Mesa Posta & Decor**.

🔗 **[Ver o protótipo clicável](https://leticiasantoslht-cmyk.github.io/projeto-rafimex/)**

---

## 📌 Contexto

A Rafimex é uma loja de artigos de mesa posta e decoração (caminhos de mesa, lugares americanos, sousplats, toalhas etc.).
A partir de uma **visita técnica à empresa**, foi identificada a necessidade de dar mais confiabilidade ao estoque:
evitar divergências entre a contagem física e o sistema e antecipar a **ruptura** (falta) dos produtos mais importantes.

## 💡 Solução proposta

O **CountMatch** é um app pensado para quem trabalha no depósito:

- **Login por matrícula** do colaborador;
- **Acuracidade do estoque**: percentual de acerto entre a contagem física e o sistema na última auditoria;
- **Ruptura por prioridade**: lista de produtos classificados como *Crítico*, *Atenção* ou *Estável* conforme a quantidade disponível;
- **Escanear código**: atalho para contar itens lendo o código do produto.

## 🖼️ Telas

|---|---|
